# Clave Valor Tipo
¿Cómo interpretar estos datos?
  • Base Nueva (personas_db): Cuando el campo base_datos es "personas_db", se usan preguntas de fecha de nacimiento y fecha de expedición.
  • Base Vieja (ani): Cuando el campo base_datos es "ani", se usan preguntas de lugar de expedición, fecha de nacimiento y nombre de padre/madre.
  • Campos clave para validación: Busca fecha_nacimiento, fecha_expedicion, lugar_expedicion, nombre_padre, nombre_madre.
